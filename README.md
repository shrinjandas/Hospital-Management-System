# Hospital Management Information System (HMIS)

A desktop application built in Java using Object-Oriented Programming (OOP) principles and Java Swing to streamline patient registration, appointment booking, and automated billing.

## Features
- **Patient & Appointment Registration:** Single-window GUI to capture patient details (name, age, contact, ailment), admission category, and doctor selection.
- **Emergency Priority Handling:** Option to flag critical or emergency cases with automatic priority surcharge calculation.
- **Automated Summary & Invoice Generation:** Instantiates domain objects on submission to display a formatted consultation summary and billing invoice in real time, with console logging support.

## Tech Stack & Concepts Used
- **Language & GUI:** Java, Java Swing
- **OOP Concepts:** Encapsulation, Inheritance, Abstraction, and Modular Class Design
